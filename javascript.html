Introducción a JavaScript

JavaScript es un lenguaje de programación que permite agregar interactividad y funciones dinámicas a la página web. Trabaja junto con HTML (estructura) y CSS (apariencia).

Es un lenguaje de programación que trabaja del lado del cliente (en el navegador del usuario). Sirve para:

  • Agregar interactividad: Responder a clics en botones.
  • Validar formularios: Comprobar que los datos ingresados sean correctos antes de enviarlos.
  • Modificar contenido: Cambiar texto, imágenes o elementos de una página sin recargarla.
  • Realizar cálculos: Procesar cantidades y resultados (como una calculadora).
  • Crear animaciones: Generar efectos y movimientos.
  • Actualizar información: Modificar partes de una página sin recargarla por completo.

Las variables son espacios identificados por un nombre que permiten almacenar datos y utilizarlos durante la ejecución de un programa.

Palabra Significado Ejemplo
var Forma antigua de declarar variables. var edad = 17;
let Variable cuyo valor puede cambiar. let edad = 17;
const Variable constante, no puede cambiar. const pais = "Mexico";

Indican qué clase de información almacena una variable. Los principales son:

  • String (Cadena): Almacena texto o palabras. Ej: let nombre = "Ana";
  • Number (Número): Almacena números enteros o decimales. Ej: let precio = 25.50;
  • Boolean (Booleano): Verdadero o falso (true/false). Ej: let activo = true;
  • Undefined: Variable declarada sin valor asignado. Ej: let resultado;
  • Null: Ausencia intencional de un valor. Ej: let usuario = null;

prompt(): Muestra una ventana donde el usuario puede escribir información. Devuelve el texto escrito.

let nombre = prompt("Ingresa tu nombre:");

confirm(): Muestra una ventana con opciones "Aceptar" y "Cancelar". Devuelve true si se acepta y false si se cancela.

let respuesta = confirm("¿Deseas continuar?");

El DOM (Document Object Model) es la forma en que JavaScript ve el HTML. Nos permite "agarrar" etiquetas HTML y modificarlas.

El método más común es getElementById(), que busca un elemento por su atributo id.

// En HTML: <p id="mensaje">Hola</p>
// En JS:
let elemento = document.getElementById("mensaje");
elemento.innerHTML = "¡Texto cambiado!";

Como prompt() y los inputs devuelven texto, necesitamos convertirlos para hacer matemáticas:

  • parseInt(): Convierte texto a número entero. Ej: let edad = parseInt("25");
  • parseFloat(): Convierte texto a número decimal. Ej: let precio = parseFloat("25.75");

Sirven para tomar decisiones. Si se cumple una condición, se ejecuta un bloque de código; si no, se ejecuta otro.

let edad = 17;
if (edad >= 18) {
    console.log("Puedes votar");
} else {
    console.log("Aún no eres ciudadano");
}

Son bloques de código reutilizables diseñados para realizar una tarea específica. Se ejecutan cuando se las llama.

function saludar() {
    return "¡Hola Mundo!";
}
// Llamar a la función:
let mensaje = saludar();
