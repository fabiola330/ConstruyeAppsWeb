Hipervínculos en HTML

En este apartado aprenderemos a insertar hipervínculos en HTML. Un hipervínculo es un elemento que conecta una página web con otra, con un archivo, o con una sección específica dentro del mismo documento.

Permite a los usuarios navegar por la web con un solo clic.

¿Cómo se crea un hipervínculo?

Se utiliza la etiqueta <a> junto con el atributo href (que indica el destino) y target="_blank" (para abrir en una nueva pestaña):

<a href="https://www.google.com" target="_blank">Dar click aquí para ir a Google</a>
