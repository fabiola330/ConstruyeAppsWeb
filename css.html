CSS (Cascading Style Sheets)

Es un estándar que define cómo se presentan los datos en el navegador. Mientras que el HTML proporciona información sobre la estructura de un documento, el CSS indica el aspecto que debe tener.

El objetivo principal del desarrollo de CSS es separar el contenido (HTML) del diseño del documento. Esta separación aumenta la accesibilidad, proporciona mayor flexibilidad y control sobre la presentación, así como reduce la complejidad y la repetición de los contenidos.

Selectores

Es un patrón de elementos que indican al navegador qué elementos HTML se seleccionan para aplicarle una regla de estilo. El elemento seleccionado se denomina sujeto del selector.

Selector Sintaxis Sirve para...
Universal * {atributo:valor;} Aplicar un estilo a todos los elementos en una página web sin excepción.
Etiqueta etiqueta {atributo:valor;} Aplicar el estilo a todos los elementos de esa etiqueta (ej. todos los <h1>).
Clase .clase {atributo:valor;} Aplicar el estilo a cualquier elemento que tenga el nombre de esa clase.

Ejemplo con selector etiqueta

h1 { color:blue; font-size:12px; }
¿Qué significa cada parte de este código?
  • h1 es el nombre del selector.
  • color es la propiedad del selector.
  • : significa que viene el valor de la propiedad.
  • blue es el valor de la propiedad.
  • ; significa cierre de la declaración.
  • font-size es otra propiedad del selector.
  • 12px es el valor de la propiedad.

¿Qué es Bootstrap?

Bootstrap es un framework que permite a los desarrolladores web construir páginas web responsivas de una forma más rápida y sencilla. Proporciona un conjunto de componentes y plantillas CSS, HTML y JavaScript que cualquiera puede utilizar o modificar de manera gratuita.
